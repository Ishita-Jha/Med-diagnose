🩺 Med Diagnose
AI-Powered Medical Diagnosis Simulation Platform
Med Diagnose is an AI-powered medical diagnosis simulation platform designed to help users practice and improve their clinical diagnostic reasoning skills through interactive, AI-generated patient cases.
The platform simulates a patient-doctor interaction where users can communicate with an AI-generated patient, ask relevant questions, request medical tests, analyze the available information, provide a final diagnosis and treatment plan, and receive an AI-based evaluation of their performance.

✨ Key Features
🤖 AI-Generated Patient Cases
Generates realistic patient scenarios using AI.
Provides different symptoms and clinical information.
💬 Interactive Patient Conversation
Allows users to communicate with the AI patient.
Users can ask questions and collect relevant clinical information.
🧪 Medical Test Simulation
Users can request appropriate diagnostic tests.
AI generates corresponding test results.
🩺 Final Diagnosis
Users submit their suspected diagnosis.
A treatment plan and confidence level can also be provided.
📊 AI-Based Performance Evaluation
Evaluates the user's diagnostic performance.
Provides feedback based on the diagnosis, treatment plan, questioning approach and clinical reasoning.
